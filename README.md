# 🚀 Космо-математика

Игра для ребёнка 5–7 лет: ракета летит по планетам, на каждой планете миссия из 8 заданий.
Работает в браузере телефона, ставится на главный экран как приложение, работает офлайн.

## Как открыть на телефоне

1. В настройках репозитория на GitHub: **Settings → Pages → Source: GitHub Actions** (один раз).
2. После пуша workflow `Deploy to GitHub Pages` выложит игру по адресу
   `https://hryndev.github.io/Test/`.
3. Открой ссылку в Chrome на Android → меню (⋮) → **Добавить на главный экран**.
   Появится иконка, игра открывается на весь экран без адресной строки.

Без GitHub Pages: файлы статические, можно открыть `index.html` с любого хостинга
или локально (`npx http-server .`).

## Что внутри

Напарник-инопланетянин Зум даёт задания, реагирует на ответы и рассказывает историю
каждой планеты. Каждое задание — это сцена в космосе:

| Тема | Сцены (24 типа заданий) |
|---|---|
| Счёт и примеры | 🔭 иллюминатор (посчитай), 🛰️ стыковка (`a + b`, три слагаемых), 🛸 улетели (`a − b` с зачёркиванием), ⛽ заправка (`a + ? = 10`), 📖 задачи-истории с персонажами, 🪞 зеркальная планета (удвоение), 🍬 поровну на две ракеты, ⚖️ на сколько больше, 📦 десяток и единицы |
| Сравнение и порядок | 🪐 на какой планете больше, ⚖️ космо-весы (`> < =`), 📡 радар (пропущенное число), 🛰️ стыковка модулей / 🚀 обратный отсчёт (по порядку), соседи числа, 🛬 ракета на числовой прямой, 🔮 загаданное число (больше 5, но меньше 8), 🏗️ нажми третью ракету, 📻 послушай число |
| Фигуры и логика | 🔧 ремонт ракеты (найди деталь, лишняя деталь, посчитай детали, сколько углов), 💡 огни взлётной полосы (узор), 🏗️ самая длинная/короткая ракета |
| Часы и деньги | ⏰ космо-часы, 🛒 космо-магазин (монетки 1/2/5/10) |

- **Звёзды:** 2 за ответ с первой попытки, 1 со второй. Планета открывается от 6 звёзд из 16,
  три звезды на планете от 14. За первое прохождение планеты даётся наклейка в альбом.
- **Ошибка:** неверный вариант гаснет, появляется подсказка (предметы для пересчёта, подписи фигур,
  цифры на часах…), голос её читает. После второй ошибки показывается правильный ответ.
- **Сложность** живая (`js/difficulty.js`): есть общий уровень 0–100% и смещение по каждому навыку.
  Общий уровень меняется после каждого ответа прямо внутри миссии (быстрый верный ответ сильнее, провал
  заметно вниз), оставшиеся задания миссии сразу перегенерируются под новую сложность. От уровня зависят
  диапазоны чисел, число вариантов и показ предметов-подсказок. Уверенный ребёнок за одну миссию
  поднимается с 25% до ~65%, два провала подряд роняют уровень на ~0.2. Модель проверена симуляцией
  (`tests/difficulty.test.mjs`). По общему уровню даётся звание: Кадет → Пилот → Штурман → Капитан →
  Командир → Адмирал галактики.
- **Напарник Зум** даёт задания в пузыре, подпрыгивает, пока говорит, реагирует на ответы. У каждой
  планеты своя история. Ракета стартует с огнём перед миссией и перелетает по карте к новой планете.
- **Турбо:** три верных подряд включают серию, на 4-й и 8-й даётся бонусная звезда.
- **Озвучка** (`js/speech.js`): синтез речи браузера (ru-RU) через очередь: фразы не перебивают друг
  друга, подсказка звучит после задания, похвала не режет подсказку, новое задание прерывает всё.
  Кнопка 🔊 повторяет задание. Задание «Послушай число» тренирует восприятие чисел на слух.
- **Для родителей:** удерживай ⚙️ на главном экране 1,2 секунды, реши пример на умножение.
  Там статистика по навыкам, история миссий, включение тем, ручной уровень, звук/голос, сброс.

Прогресс хранится в `localStorage` телефона.

## Разработка

```
node --test tests/*.test.mjs   # генераторы, сложность (симуляция), озвучка
npx http-server .      # локальный запуск
```

- `js/tasks.js` — генераторы заданий (чистые функции, без DOM), `generate(skill, d)`, d — сложность 0..1.
- `js/difficulty.js` — модель сложности и званий, `js/speech.js` — очередь озвучки.
- `js/app.js` — экраны, обработка ответов, подсказки, звук, анимации.
- `css/style.css` — стили, мобильная вёрстка.
- `sw.js`, `manifest.webmanifest`, `icons/` — PWA.
