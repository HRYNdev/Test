# 🚀 Космо-математика

Игра для ребёнка 5–7 лет: ракета летит по планетам, на каждой планете миссия из 8 заданий.
Работает в браузере телефона, ставится на главный экран как приложение, работает офлайн.

## Как открыть на телефоне

1. В настройках репозитория на GitHub: **Settings → Pages → Source: GitHub Actions** (один раз).
2. После пуша workflow `Deploy to GitHub Pages` выложит игру по адресу
   `https://hryndev.github.io/Test/`.
3. Открой ссылку в Chrome на Android → меню (⋮) → **Добавить на главный экран**.
   Появится иконка, игра открывается на весь экран без адресной строки.

Без GitHub Pages: файлы статические, можно открыть `index.html` с любого хостинга
или локально (`npx http-server .`).

## Что внутри

| Тема | Задания |
|---|---|
| Счёт и примеры | посчитай предметы, `a + b`, `a − b` (с зачёркиванием предметов) |
| Сравнение и порядок | где больше/меньше, знак `> < =`, пропущенное число, расставь по порядку |
| Фигуры и логика | найди фигуру, что лишнее, посчитай треугольники, продолжи узор |
| Часы и деньги | который час (стрелки), посчитай монетки 1/2/5/10 ₽ |

- **Звёзды:** 2 за ответ с первой попытки, 1 со второй. Планета открывается от 6 звёзд из 16,
  три звезды на планете от 14. За первое прохождение планеты даётся наклейка в альбом.
- **Ошибка:** неверный вариант гаснет, появляется подсказка (предметы для пересчёта, подписи фигур,
  цифры на часах…), голос её читает. После второй ошибки показывается правильный ответ.
- **Сложность** подбирается по каждому навыку отдельно: 3 верных подряд с первой попытки повышают
  уровень, 2 провала подряд понижают. Вычитание стартует с лёгкого уровня и встречается чаще других.
- **Озвучка:** синтез речи браузера (ru-RU). Кнопка 🔊 повторяет задание.
- **Для родителей:** удерживай ⚙️ на главном экране 1,2 секунды, реши пример на умножение.
  Там статистика по навыкам, история миссий, включение тем, ручной уровень, звук/голос, сброс.

Прогресс хранится в `localStorage` телефона.

## Разработка

```
node --test tests/tasks.test.mjs  # тесты генераторов заданий
npx http-server .      # локальный запуск
```

- `js/tasks.js` — генераторы заданий (чистые функции, без DOM).
- `js/app.js` — экраны, обработка ответов, подсказки, звук, речь, адаптивная сложность.
- `css/style.css` — стили, мобильная вёрстка.
- `sw.js`, `manifest.webmanifest`, `icons/` — PWA.
